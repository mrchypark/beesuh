## Evidence limits

The listed tests use local fixtures, disposable data directories, and controlled
processes. They can prove the repository boundary named in each row. They cannot
prove that a real Conductor gateway enforces scope or idempotency, that a real IdP
binds and validates a human token, or that a deployed provider and binary honor the
same protocol and process behavior. Those require deployment-specific evidence.

Open issue [#19](https://github.com/mrchypark/beesuh/issues/19) retains these external obligations from #13. Fixture success is not evidence that
the production gateway, IdP, or provider is configured correctly.
